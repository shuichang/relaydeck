# v0.1.5：规则错误恢复、字体与 SSL 设置

## 改动

- 转发运行状态按 TCP、UDP 及监听器区分当前未恢复错误。恢复后保留最近错误内容、发生时间和恢复时间，避免旧超时一直被显示成当前故障。
- TCP 建立上游后恢复对应临时错误；UDP 只有收到真实目标回包才恢复。并发恢复使用序号保护，不覆盖较新的错误，TCP 成功不会掩盖 UDP 故障。
- 规则名称、地址、限制、检测结果和运行状态增大字体，并调整桌面和手机布局。
- 增加“设置 → SSL 证书”，支持上传/粘贴 PEM、服务器文件路径、自签 IP/域名证书和恢复启动默认证书。
- 证书验证和持久化成功后热更新，不重启已有 HTTP 请求或转发连接。文件来源每 60 秒检查续期；错误文件继续保留最后有效证书，重启后也可恢复。
- 私钥只可提交，不回显、不进入普通配置导出；证书和私钥成对原子保存在权限为 `0600` 的独立设置文件中。

## 验证范围

测试覆盖真实 TCP 故障与恢复、UDP 回包判定、协议错误隔离、并发错误更新、真实 TLS 握手期间轮换、错误私钥/坏证书链/过期证书拒绝、磁盘写入失败不激活、首次默认启动后半完成续期的重启回退，以及认证、CSRF 和私钥不回显。

设置页提供证书配置与续期文件重载，不自动申请 ACME 证书。更换证书后的域名匹配及浏览器信任仍由实际访问方式和 CA 决定。
