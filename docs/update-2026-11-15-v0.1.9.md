# v0.1.9：Alpine/OpenRC 安装支持

本版本修复 Alpine 3.23 LXC 容器执行安装脚本时因没有 `systemctl` 而提前退出的问题。

- 安装器自动识别 systemd 或 OpenRC。
- OpenRC 使用 `/etc/init.d/relaydeck`、`rc-service` 和 `rc-update` 管理面板。
- OpenRC 健康检查读取 `/run/relaydeck.pid`，并确认监听端口属于 RelayDeck 进程。
- Alpine 缺少 `ss` 时自动通过 `apk` 安装 `iproute2`，用于安装后的监听与健康检查。
- 更新、端口保留、失败回滚和卸载流程同时适配两种服务管理器。
- 修复服务模板生成时管理端口没有写入实际数字的问题。

Alpine 安装示例：

```bash
curl -fsSL https://raw.githubusercontent.com/shuichang/relaydeck/main/scripts/install.sh \
  | bash -s -- --port 18443
```

安装成功后可使用：

```bash
rc-service relaydeck status
curl -kfsS https://localhost:18443/healthz
```
