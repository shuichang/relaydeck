GUIDE

使用帮助

关于规则、安全、协议内核和主题的快速说明。

01

创建转发规则

填写监听地址与目标地址。端口可写成 :443、0.0.0.0:443、[::]:443 或具体的 IPv4/IPv6 地址。目标必须是 IPv4 字面量，或解析到 IPv4 的主机名。

02

协议与 UDP

规则可选择 TCP、UDP 或两者。UDP 会话有独立空闲超时；高并发场景请结合实际协议和应用回包路径设置超时与连接上限。

03

访问控制

使用 CIDR 限制来源地址，每行或逗号分隔一项。连接上限为 0 时不额外限流。规则的变更会原子保存；绑定失败时服务端会恢复原规则。

04

协议内核

内核页用于编辑 sing-box 配置。未安装 sing-box 时不能保存或启动；配置校验和进程启动均成功后才持久化。日志与版本来自后端状态接口。

05

密码与安全

本面板不会把密码写入 localStorage、sessionStorage 或 Cookie 脚本内容。会话使用服务器的 HttpOnly Cookie，所有写操作附带 CSRF 请求头。

06

主题与轮询

可在侧栏切换深色、浅色或跟随系统。状态只在页面可见时定时刷新；切到后台会暂停轮询，回到页面后立即更新。

部署建议

通过 HTTPS 访问管理面板，限制管理端口来源，并定期更新 RelayDeck 与可选协议内核。导出配置包含转发节点凭据，但不包含管理员密码，请妥善保存导出文件。
